# Meme Generator 😂

A fun and simple React-based meme generator app.

## 🚀 Features
- Fetches random meme images from an API
- Allows user to add top and bottom text
- Generates meme with custom text overlay
- Clean and responsive UI

## 🛠 Tech Stack
- React
- JavaScript
- HTML/CSS

## 🧪 Run Locally

```bash
npm install
npm run dev
